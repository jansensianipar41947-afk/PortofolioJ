Rincian Lengkap Skripsi S-1

ANALISIS KOMPARASI ALGORITMA LONG SHORT-TERM MEMORY (LSTM) DAN GATED RECURRENT UNIT (GRU) DENGAN OPTIMASI HYPERPARAMETER UNTUK PREDIKSI TREN POLUSI UDARA

1. Latar Belakang & Rumusan Masalah

Polusi udara dari pergerakan kendaraan bermotor di area kampus memicu fluktuasi partikulat skala mikro yang ekstrem (PM2.5 & PM10). Stasiun pemantauan pemerintah berskala makro tidak mampu menangkap lonjakan lokal ini secara real-time. Penelitian ini membangun node akuisisi IoT khusus (NodeMCU ESP8266 + sensor laser PMS5003T) yang mengirimkan data setiap 1 menit ke penyimpanan cloud ThingSpeak.

2. Metodologi & Pipeline Pra-pemrosesan

  • Pembersihan Data: Penghapusan outlier untuk pembacaan >300 µg/m³ (menghilangkan gangguan listrik pada perangkat keras).
  • Augmentasi Data: Mengatasi ketidakseimbangan kelas ISPU dengan mengintegrasikan data rekan dan menerapkan injeksi Gaussian Noise serta interpolasi linear lokal (mencapai 3,557 baris seimbang).
  • Pembentukan Sekuens: Membentuk sliding window sekuensial 3D [sampel, 10 timestep, 2 fitur].
  • Tuning Hyperparameter: Grid Search menyeluruh pada Epoch {50, 100} dan Batch Size {32, 64}.

3. Ringkasan Evaluasi Kuantitatif

Model LSTM (50 Epoch, Batch 64): • RMSE: 17.7647 µg/m³
• MAE: 10.1312 µg/m³
• RAM Inferensi Uji: 34.77 MB
Model GRU (50 Epoch, Batch 64): • RMSE: 18.1988 µg/m³
• Akurasi ISPU PM10: 85.30% (F1: 85.37%)
• RAM Inferensi Uji: 5.91 MB

4. Rekomendasi Praktis untuk HR & Tim Teknis

Meskipun LSTM menghasilkan error regresi yang sedikit lebih rendah, GRU sangat direkomendasikan untuk deployment di edge pada NodeMCU ESP8266 karena jejak memorinya 6x lebih kecil (5.91 MB vs 34.77 MB) sehingga mencegah crash sistem akibat Out-of-Memory (OOM).
